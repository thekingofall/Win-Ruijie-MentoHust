# 版本验证范围

0.5.1 适用于 Windows 有线校园网，沿用本机安装的抓包驱动和锐捷客户端校验文件。

43 项自动测试通过，覆盖认证报文、心跳、注销、网卡定位、DHCP 调用、密码加密与启动设置。离线窗口检查验证了关闭收起、托盘恢复、自动连接后收起、失败时保留提示，以及退出时结束认证任务。打包程序通过窗口初始化、DPAPI 加解密和抓包运行库识别检查。

此前的 0.5.0 在一台 Windows 电脑上完成了校园网认证、DHCP 和关闭 Wi-Fi 后的有线 HTTPS 访问测试。这些结果对应具体测试环境，其他学校的认证策略需要实际验证。

0.5.1 已完成本机启动任务与快捷方式更新；实际重启 Windows 后的自动登录，以及新版联网状态下的托盘操作现场检查仍待完成。

公开测试材料包含模拟数据和空白账号界面。实际账号、密码、网络地址、设备标识和现场日志保存在本地。
